# Scientific lineage

This repository separates the frozen scientific core, later held-out extensions, and post-hoc sensitivity analyses.

## Frozen scientific core

The frozen core includes the participant split, subjective-report benchmark, direct EEG outcome tests and diagnostics, outcome-free local-state/cross-participant alignment, three-epoch trajectory geometry, fixed held-out structural transfer, and initial semantic stress tests.

## Later held-out extensions

Subsequent specifications evaluate multiresolution experience structure, report-transition structure, splitwise semantic/report mappings, compact EEG signal-space characterization, topographic transfer, and peripheral-physiology boundaries. These extensions preserve the original participant splits and do not retroactively alter the frozen core.

Here, “prespecified” means frozen before the relevant held-out split or target values were evaluated within this secondary analysis. It does not imply prospective preregistration before the original data collection.

The multiresolution structures meet their frozen cross-split structural-transfer criteria. Later post-hoc calibration shows that the held-out in-support component is permissive under a matched continuous Gaussian reference, so transfer support is interpreted as geometric compatibility rather than null-specific evidence of discrete latent organization.

## Semantic target lineage

The event-grammar audit identifies and avoids an invalid row-number context rule. Discovery context is event-derived and stimulus/category targets are attached through context-specific sequence position. Validation and Confirmation semantic specifications prohibit canonical stimulus/category targets and reconstruct held-out targets from authoritative context plus the frozen README sequence parser. The final semantic evidence table contains 27 parent tests across the three splits, with no multiplicity-adjusted rejection.

## Post-hoc sensitivity analyses

The experience-to-report analyses, trajectory-discreteness audit, cluster-independent axis audit, multiresolution continuous-null calibration, existing-QC exclusion sensitivity, and within-trial continuity analysis are explicitly post hoc. They refine interpretation but are not independent external confirmation.

## Repository curation

Workstation-specific paths, private execution artifacts, and project-management records are excluded. Scientific specification identifiers and source-lineage hashes are retained because they are part of the reproducibility record.
