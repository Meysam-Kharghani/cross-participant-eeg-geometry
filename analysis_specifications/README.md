# Analysis specifications

This directory contains scientific design, transfer, and inference specifications retained for auditability. Sequential identifiers (`S001`, `S002`, …) index scientific specification records and are retained as provenance identifiers. Reference implementations used by held-out transfer specifications are under `reference_code/`.

The term *prespecified* in these records means frozen before the relevant held-out split or target values were evaluated within this secondary analysis; it does not imply preregistration before the original data collection.
