# Provenance

`CHECKSUMS.sha256` records SHA-256 hashes for repository files except the checksum manifest itself.

`SCIENTIFIC_LINEAGE.md` distinguishes the frozen scientific core, later held-out extensions, and post-hoc sensitivity analyses. `EVIDENCE_INDEX.md` maps the major evidence branches to repository artifacts. `UPSTREAM_SOURCE_HASHES.csv` records cryptographic identifiers for curated upstream scientific sources where applicable.
